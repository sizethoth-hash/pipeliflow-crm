10 — Filosofia

Princípios de Design

Os princípios que guiam decisões de UX e UI ao longo do desenvolvimento do produto.

Clareza sobre Complexidade

Cada tela deve comunicar uma coisa principal. Hierarquia visual clara — tamanho, peso e cor guiam o olhar sem necessidade de instrução. Nenhum elemento está presente por decoração.

Velocidade é Funcionalidade

Um CRM lento é um CRM que não é usado. Componentes otimizados para render mínimo. Server Components por padrão. Feedback imediato em toda interação com estado de loading explícito.

Segurança por Padrão

RLS no Supabase garante que nenhum dado vaze entre workspaces. Nunca bypassar via service role no cliente. Toda operação destrutiva exige confirmação explícita do usuário.

Acessibilidade é Obrigatória

WCAG 2.2 AA em todos os componentes interativos. Contraste mínimo 4.5:1 para texto, 3:1 para elementos gráficos. Navegação completa por teclado. Focus ring sempre visível.

Consistência Sistemática

Tokens de design centralizados em variáveis CSS. Mesmos valores de espaçamento, raio e sombra em todo o sistema. Novos componentes seguem os existentes — não inventam novos padrões.

Dados no Centro

O produto existe para surfaçar informação acionável. Dashboard e métricas não são enfeite — são a razão do CRM existir. Cada decisão visual serve aos dados, não o contrário.
